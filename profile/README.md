BrainArts Lab builds open-source plugins and bots for [Hermes Agent](https://github.com/NousResearch/hermes-agent).

## Bot Drops

Share your Hermes bot with a link and a preview card. Others can review what it includes and make it their own in Hermes.

[![Three steps: share your bot, get a link and a card, anyone makes it theirs](https://raw.githubusercontent.com/brainarts-lab/bot-drops/main/assets/how-it-works.png)](https://github.com/brainarts-lab/bot-drops)

```sh
hermes plugins install https://github.com/brainarts-lab/bot-drops --enable
```

[Plugin and docs](https://github.com/brainarts-lab/bot-drops)

## Launch Buddy

A bot shared with Bot Drops. Paste your README and it answers with a one-line pitch, a launch post and a 60-second demo script.

[![Launch Buddy, a Hermes bot shared with Bot Drops](https://brainarts-lab.github.io/launch-buddy/drop-card.png)](https://brainarts-lab.github.io/launch-buddy/)

[Open the bot page](https://brainarts-lab.github.io/launch-buddy/) · [Files](https://github.com/brainarts-lab/launch-buddy)
