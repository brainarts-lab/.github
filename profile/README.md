BrainArts Lab builds open-source plugins and bots for [Hermes Agent](https://github.com/NousResearch/hermes-agent).

## Hebe Longevity

Personal Longevity Intelligence for Hermes, built on Insilico Medicine's open PLSI toolbelt. Reads nine values from a routine blood test, calculates your Blood PhenoAge, tracks what moved it across draws and drafts safety-screened research plans challenged by a separate model call before you start a plan.

[![Hebe Longevity for Hermes Agent](https://raw.githubusercontent.com/brainarts-lab/hebe-longevity/763711e9183f9bc9d88daea89aa181f181db6f6b/assets/hebe-banner.png)](https://github.com/brainarts-lab/hebe-longevity)

```sh
hermes plugins install https://github.com/brainarts-lab/hebe-longevity --enable
```

[Plugin and docs](https://github.com/brainarts-lab/hebe-longevity)

## Bot Drops

Share your Hermes bot with a link and a preview card. Others can review what it includes and make it their own in Hermes.

[![Three steps: share your bot, get a link and a card, anyone makes it theirs](https://raw.githubusercontent.com/brainarts-lab/bot-drops/2b2d9f7e698bdef76507491ffef48f7bd18be699/assets/how-it-works.png)](https://github.com/brainarts-lab/bot-drops)

```sh
hermes plugins install https://github.com/brainarts-lab/bot-drops --enable
```

[Plugin and docs](https://github.com/brainarts-lab/bot-drops)

## Launch Buddy

A bot shared with Bot Drops. Paste your README and it answers with a one-line pitch, a launch post and a 60-second demo script.
